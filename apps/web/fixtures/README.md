# apps/web/fixtures

Example report files for the two newest console pages (State × Strategy Matrices, Router Paper
Runs), laid out exactly like a real report root (`<kind>/<id>.json`) so this directory can be
passed straight to `apps.api.create_app(reports_root=...)` for local `npm run dev` use — see
[../README.md](../README.md) "用 `apps/web/fixtures/` 快速起一个有数据的后端".

Generated by `research/reports`' real writers (`write_state_strategy_matrix`,
`write_router_paper_run`) over the same fixture objects `tests/research/experiments/test_state_strategy.py`
and `tests/research/router/test_paper.py` use — the JSON here is byte-identical to what those
writers produce for those objects, not hand-written example data. Regenerate after changing either
writer's payload shape (e.g. rerun the writers over the same fixtures and overwrite these files;
the writer's append-only rule refuses a conflicting rewrite under the same id, so a changed payload
also changes the filename since the id is a content hash).

No fixtures for `validation_report` / `research_loop_round` — those two pages already shipped with
the previous console note and were not part of this batch.
