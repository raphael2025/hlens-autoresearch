> 原则：**宁可说明"这个门槛不适合固定成一个数字"，也不制造虚假的精确性。**

---

## 0. 核心观点（给 Raphael 的一页摘要）

1. **五类门槛中，大多数不应是一个固定数字。** 合理门槛取决于交易频率、持仓周期、尝试次数和策略类别。
2. **建议分三层：**
   - **Constitution**（不可变原则）：规定"必须有什么门槛、如何使用"，不写具体数字。
   - **Validation Profile**（版本化参数）：按"标的 × 周期 × 策略类别"给出具体数字。
   - **Experiment Metadata**（每个实验记录）：记录使用的 Profile 版本、尝试次数和实际计算值。
3. **12 个月样本外（OOS）无法单独"证明"一个年化 Sharpe 约 1 的策略。** 在 iid 近似下，年化 SR 估计的标准误约为 1/√年数，所以 1 年 OOS 的 t 值约等于 SR 本身。因此 OOS 的作用应定义为**检验衰减与一致性**，而不是独立的显著性证明（详见 §D）。
4. **最干净的样本外是未来数据**，也就是 PAPER 阶段。你在旧项目中很可能已经看过 BTC 的全部历史，历史区间里的"封存样本"在人的认知层面并不完全干净（问题 H-3）。
5. **建议分两步冻结：** Phase 0 先批准原则和临时参数（v0.x）；Phase 4 在真实数据上完成空模型校准后冻结 v1.0，**然后才允许 Phase 5 的策略实验**。

## 1. 为什么单一固定数字会造成错误筛选

| 问题 | 例子 |
|---|---|
| 忽略交易频率 | "OOS = 12 个月"对年交易 20 次和 2000 次的策略一视同仁：前者样本不足，后者对它过于宽松 |
| 忽略尝试次数 | 固定 "SR > 1.5" 不考虑试了多少组合。尝试 1 次和 1000 次时，偶然达到的最大 SR 完全不同 |
| 忽略样本重叠 | 固定"至少 100 笔交易"时，持仓互相重叠的交易并不独立，有效样本远少于 100 |
| 悬崖效应 | 1.49 被拒、1.51 通过，研究者会被诱导去微调刚好越过门槛（Goodhart） |
| 忽略市场体制 | 12 个月 OOS 若恰好全是单边牛市，长度够了，信息量却很少 |
| 忽略策略类别 | 用买入持有作基准对多头策略合理，对市场中性或做空策略没有意义 |

结论：Constitution 应当固定**原则和方法**；数字放进版本化 Profile，并用**连续指标 + 报告区间**代替单点判定。

## A. 建议的 Constitution 不可变原则

这些原则不含具体数字。修改需要 ADR，且只对之后登记的实验生效。

| ID | 原则 |
|---|---|
| A-1 | 每个实验在**运行前**绑定一个 Validation Profile 版本，之后不可更换 |
| A-2 | Profile 由**确定性映射规则**选定（标的、周期、预登记的持仓类别），研究者不能自由选择 |
| A-3 | 每个 Profile 必须为五类门槛（OOS、样本量、基准、参数稳定性、成本压力）都给出判定规则；缺任何一类的 Profile 无效 |
| A-4 | 显著性判断必须考虑**假设族的累计尝试次数**（多重检验校正） |
| A-5 | 样本量以**有效独立样本**计，不能按 bar 数或重叠交易数计算 |
| A-6 | 必须与**空模型**（相同交易次数和持仓分布下的随机进出）比较，而不只是与市场基准比较 |
| A-7 | 所有收益必须扣除成本，并通过成本压力测试 |
| A-8 | 必须检验参数邻域的稳定性；只在孤立参数点上成立的结果无效 |
| A-9 | 封存样本外区间的每次开封都要审计记录；开封次数计入全局预算 |
| A-10 | Profile 修改只对之后生效；**不得**以任何实验结果作为修改理由；不得用新 Profile 重新判定已 REJECTED 的对象 |
| A-11 | Profile 冻结前必须完成空模型校准（§E），校准结果作为批准依据 |
| A-12 | 结果落在灰区（接近门槛）时判为 `INCONCLUSIVE` 而不是 PASS，记录后等待更多数据（如 PAPER） |

## B. 建议的 Validation Profile 结构

Profile ID 示例：`vp:btcusdt-1h-swing@0.1.0`

| 字段组 | 字段 |
|---|---|
| 适用范围 | instrument、venue、bar 周期、策略类别（按预登记的持仓周期划分） |
| 数据切分 | 研究窗口、封存 OOS 区间（固定日期边界）、embargo、walk-forward 配置 |
| 样本量 | 最小有效独立交易数（IS / OOS / 每个状态分组） |
| 显著性 | DSR 阈值、PBO 阈值、报告项（t 值、bootstrap 置信区间） |
| 基准 | 空模型设定与分位阈值；按策略类别适用的市场基准 |
| 参数稳定性 | 邻域定义、邻域表现下限、bar 偏移测试 |
| 成本 | 基准成本模型 `name@version`、压力倍数、延迟压力、盈亏平衡成本要求 |
| 灰区 | 各门槛的 INCONCLUSIVE 区间 |
| 生命周期 | PAPER 观察期长度、劣化监控阈值（与 ADR-0006 Q-6 相关） |
| 元数据 | 版本、校准报告引用、批准 ADR |

**Experiment Metadata**（每次运行记录）：Profile ID 与版本、假设族 ID、族内累计尝试次数、预登记的持仓类别与实际持仓分布、各门槛的计算值与判定。

## C. 建议的 BTCUSDT 1H 初始参数（v0.1，临时，未校准）

策略类别（按预登记的中位持仓周期）：
- **Intraday**：1–24 bar
- **Swing**：24–240 bar
- **Position**：> 240 bar。1H 数据下年交易次数很少，**暂不纳入 v0.1**，需要单独的 Profile。

### C-1 OOS 区间（对应 TBD-1）

| 参数 | Intraday | Swing | 说明 |
|---|---|---|---|
| 封存 OOS | 最近 12 个完整自然月 | 同左 | 固定**日期边界**，不按"运行时往前推 12 个月"滚动 |
| OOS 最小有效交易数 | ≥ 100 | ≥ 30 | 不足时 OOS 最多延长到 24 个月；仍不足则判 `INSUFFICIENT_EVIDENCE`，**不判通过** |
| OOS 判定 | OOS 净收益 > 0，**且** OOS SR 不低于"IS 同长度 block bootstrap 分布"的第 5 分位 | 同左 | 检验一致性与衰减，而非独立显著性 |
| embargo | ≥ max(最长 Outcome horizon, 24 bar) | ≥ max(horizon, 72 bar) | purging 规则见 Constitution C-L5 |
| walk-forward | 滚动：训练 24 个月 / 测试 3 个月 / 步长 3 个月 | 训练 36 个月 / 测试 6 个月 / 步长 6 个月 | 只在研究窗口内进行 |
| walk-forward 判定 | ≥ 60% 的测试窗口净收益为正；单个窗口贡献 ≤ 40% 的总净 PnL | 同左 | 防止收益集中在个别时期 |

### C-2 最小样本量（对应 TBD-2）

| 参数 | Intraday | Swing |
|---|---|---|
| IS 最小有效独立交易数 | ≥ 300 | ≥ 100 |
| 条件化结论中每个状态分组 | ≥ 50（低于此数只报告，不判定） | ≥ 30 |
| IS 覆盖范围 | 至少 3 年，且包含至少一个完整的上涨阶段和一个完整的下跌阶段 | 同左 |

"有效独立"：持仓重叠的交易按重叠度折算；事件研究中相距小于 horizon 的事件只算一次。

### C-3 显著性与基准（对应 TBD-3）

| 参数 | 值 | 说明 |
|---|---|---|
| Deflated Sharpe Ratio | DSR ≥ 0.95 | 尝试次数 = 假设族累计值 |
| PBO（CSCV，S = 16） | ≤ 0.20 | 适用于有参数搜索的实验 |
| 空模型 | 随机进出（交易次数、多空比例、持仓时长分布与策略相同），≥ 1000 次模拟 | 净 SR 须高于空模型分布的第 95 分位 |
| 市场基准 | 多头或偏多策略：与买入持有比较风险调整后收益和最大回撤；中性或做空策略：不使用买入持有 | 按类别适用 |
| 反向对照 | 报告信号取反后的表现 | 只报告；若取反同样显著，提示结果可能来自波动暴露而非方向判断 |
| 报告项 | Harvey-Liu-Zhu t 值、block bootstrap 置信区间 | 只报告，不作为门槛 |

### C-4 参数稳定性（对应 TBD-4）

| 参数 | 值 |
|---|---|
| 邻域定义 | 每个参数 ±1 个预登记网格步长（网格步长约为参数值的 10–20%）；连续参数取 ±10% 和 ±20% |
| 邻域表现 | 邻域净 SR 中位数 ≥ 选定点的 50%，且 ≥ 70% 的邻域点净收益为正 |
| bar 偏移 | 1H bar 起点平移 15、30、45 分钟后，净收益为正，且净 SR ≥ 基准设定的 50% |
| 参数漂移 | 各 walk-forward 窗口的最优参数只报告（不作门槛），剧烈跳变须在报告中标出 |

### C-5 成本压力（对应 TBD-5）

| 参数 | 值 | 说明 |
|---|---|---|
| 成交假设 | t 时 bar 收盘产生信号，t+1 bar 开盘成交 | — |
| 基准手续费 | 按所选 venue 和产品的实际费率档位（Binance VIP0 参考：现货 0.10%；USDⓈ-M 永续 taker 0.05%） | **批准时须按当时实际费率核实**；产品类型取决于 D-08 |
| 基准滑点 | 每边 2 bp | 对 BTCUSDT 小资金规模偏保守；Phase 1 后用真实盘口数据校准 |
| 资金费率 | 永续合约使用历史实际资金费率 | — |
| 压力 1 | 总成本 × 2：净收益仍为正，DSR 仍 ≥ 0.90 | — |
| 压力 2 | 总成本 × 3 | 只报告 |
| 延迟压力 | 成交再延迟 1 bar：净收益仍为正 | — |
| 盈亏平衡成本 | ≥ 2 × 基准总成本 | 报告"成本升到多少时优势消失" |

## D. 为什么选择这些参数

1. **OOS 12 个月 + 最小交易数 + 一致性判定。**
   - 在 iid 近似下，年化 SR 的标准误约为 1/√Y（Y 为年数，参见 Lo 2002）。
   - 真实 SR = 1 的策略：1 年 OOS 的 t ≈ 1；要达到 t ≈ 2 需要约 4 年，t ≈ 3 需要约 9 年。
   - 所以没有任何可行的 OOS 长度能单独证明中等 SR 的策略，**显著性只能来自 IS 阶段经多重检验校正后的检验**。
   - OOS 的任务是发现过拟合带来的衰减，因此判定标准定为"与 IS 分布一致"，并用交易数下限保证至少有基本的信息量。
   - 12 个月能覆盖加密市场的季节性和多种短期状态，也不会从研究窗口拿走太多数据。
   - 如果按"运行时往前推 12 个月"滚动，封存区会随着时间悄悄变成研究数据，所以采用固定日期边界。
2. **样本量按有效独立交易计。**
   - 1H 数据中持仓重叠非常普遍，按 bar 数计算会严重高估样本量。
   - 300 / 100 的起点依据：加密收益厚尾，30 左右的"经典小样本"对均值和尾部估计都太不稳定。
   - 这两个数字最需要 §E 的校准来修正。
3. **DSR + PBO。**
   - Bailey & López de Prado（2014）的 Deflated Sharpe Ratio 直接把尝试次数纳入判断。
   - Bailey 等（2014，Minimum Backtest Length）表明：要求年化 SR ≥ 1 且不被噪声偶然达到时，5 年数据下独立尝试次数不宜超过约 45 次。
   - Phase 7 的自动组合会产生大量尝试，没有这一校正，系统会系统性地制造假发现。
   - PBO（Bailey, Borwein, López de Prado, Zhu 2015）衡量参数选择过程本身的过拟合概率。
   - 0.95 和 0.20 是文献与业界常见的起点，**不是**由本项目数据推导出来的。
4. **以空模型为主基准。** 单一标的的时间序列策略很容易从"持有 BTC 的时间比例"中获得收益。随机进出空模型能分离出择时本身的贡献，比买入持有更有针对性（参见 White 2000 Reality Check、Hansen 2005 SPA 的思路）。
5. **参数邻域 + bar 偏移。**
   - 只在孤立参数点上成立的策略几乎都是过拟合。
   - bar 偏移测试是针对 1H bar 的检查：若策略依赖整点边界，往往是在利用数据构造方式而非市场规律。
6. **成本 × 2 + 延迟 1 bar。**
   - 回测中最常被低估的就是成本和延迟。1H 中频策略的换手率可能很高，成本敏感度差异很大。
   - 盈亏平衡成本比单一压力倍数更能说明策略离失效还有多远。
7. **中低频与短周期的差异。**
   - 短周期（分钟级）策略样本多，OOS 可以更短，但成本、排队和盘口冲击占主导，需要订单簿级别的成本模型。
   - 中低频（小时到天）成本影响小，但样本少，时期依赖更强。
   - 因此 Profile 必须按周期和类别分开，本提案只覆盖 BTCUSDT 1H 的 Intraday 和 Swing 两类。
8. **样本长度与市场非平稳。**
   - BTCUSDT 现货数据约从 2017-08 开始（Binance），永续合约约从 2019-09 开始。
   - 更长的历史有助于多重检验（MinBTL），但 2017–2019 年的市场结构与今天差异很大。
   - 所以要求覆盖多个市场阶段，并**按时期分段报告**，而不是简单地越长越好。

## E. 敏感性分析与校准方法

目标：选出"判定结果对门槛小幅变化不敏感"的数值，并在批准前知道整个流程的假阳性率和检出力。

1. **空模型校准（假阳性率）。** 在真实 BTCUSDT 1H 数据上生成大量随机策略（随机进出、打乱信号、符号随机化），让它们走完整条验证流程，统计最终 PASS 的比例。**目标假阳性率由 Raphael 决定（H-5）。**
2. **植入效应（检出力）。** 在真实收益序列上植入已知强度的可预测成分（例如年化 SR 为 0.5、1.0、1.5、2.0），统计各强度被正确判为 PASS 的比例。这样就知道系统"能看见多强的信号"。
3. **门槛扫描。** 把每个门槛按 ±25% 和 ±50% 变动，观察校准集（空模型 + 植入效应 + 少量文献经典策略）的判定翻转情况。选择**平坦区域**内的数值，避开悬崖。
4. **先校准后使用。** 校准只使用空模型、植入效应和文献基准，**不使用任何真实候选策略**；完成后才冻结 Profile v1.0。
5. **时间点。** 校准需要 Phase 1 的数据和 Phase 4 的验证流程，所以 v1.0 最早在 Phase 4 结束时冻结，排在 Phase 5 策略实验之前。Phase 1–3 只研究 Feature、State、Event，不涉及策略判定，临时 v0.x 足够。
6. **重新校准。** 只能发布新的 Profile 版本，只对之后登记的实验生效。

## F. 未来允许版本化的参数

- 所有数值门槛（交易数、DSR、PBO、邻域比例、压力倍数、灰区范围）
- 成本模型参数（交易所费率会变化）
- 封存 OOS 的日期边界（按轮换规则发布新版本；旧封存区转为研究数据，并记录它已被使用过的次数）
- walk-forward 配置、空模型的模拟次数
- 新的标的、周期或策略类别的 Profile
- PAPER 观察期长度、劣化监控阈值

版本化条件：ADR + Raphael 批准 + 校准报告；只对之后生效。

## G. 禁止因为结果而改变的内容

- 已登记实验所绑定的 Profile 版本及其全部参数
- 假设族评估期间的封存 OOS 边界
- 尝试次数的计算方法（包括"失败的尝试也计入"）
- Profile 映射规则（不得把实验重新归类到更宽松的类别）
- 已登记实验的成本模型版本
- 已 REJECTED 对象的判定（不得用新 Profile 重新判定来"挽救"）
- "没有任何策略通过"**不是**放宽门槛的理由；它是需要如实报告的研究结论
