# plugins/

通用 / 基础设施类 Provider 与 Adapter：Collector、Backtest、Knowledge、LLM、SyntheticMarket、Storage、Catalog 等（05-plugin.md）。

## 当前内容

| 模块 | 用途 |
|---|---|
| `backtest/` | Phase 5（ADR-0038）`BarBacktester`：确定性、`Decimal`、bar 级回测 v1；下一根 bar 开盘成交，成本模型 = 费率 + 不利滑点；**只是模拟**（无下单、无密钥、无网络）；经 `tests/contract_suites/backtest.py` 的基准一致性检查。可选 `ExecutionModel`（`BarBacktester(execution=...)`，全部参数显式、无默认）：bar 成交量参与上限（剩余量在执行 bar 取消并报告；`carry_over=True` 时改为 ADR-0054 的 `next_bar_open_participation`：剩余量按 `PriceBar.volume` 结转到之后的 bar，直到成交完、被下一目标取代或数据结束，记录在 `BacktestResult.remainders`，version `1.2.0+exec.<fingerprint>`）、与 G4 容量检查同一公式的平方根冲击、逐 bar 步的借券 / 现金融资（计入权益）；参数与成交量经 version `1.1.0+exec.<fingerprint>` 绑定进 `provider_hash`，默认构造与 v1 逐字节相同（ADR-0038 实施说明 execution realism） |
| `events/` | Phase 3（ADR-0036）首批 `EventProvider`：`FeatureThresholdCrossProvider`、`VolatilityBreakoutProvider`、`StateSwitchProvider` 与交互算子 `EventSequenceProvider`、`EventCoOccurrenceProvider`——确定性、精确 `Decimal`；参数写入 `EventSpec.trigger` 的规范 JSON 并由 spec hash 绑定；交互输出引用上游 `event_id`；只依赖 `core`，经 `tests/contract_suites/event.py` 检查。后续增补：`features.py` 的 `FeatureRelativeThresholdCrossProvider`；`windows.py` 的 `EventWindowEndProvider`、`EventAbsenceProvider`、`EventCountProvider` 与 `dsl.py` 事件交互 DSL（ADR-0061，表达式编译为普通交互规格） |
| `events/p7_temporal.py` | P7 `temporal` 算子执行 Provider（ADR-0082 第三次接受、ADR-0088、ADR-0100 §1 及修订 1）：`P7TemporalSequenceProvider`（`p7_temporal_sequence@1.0.0`），只服务 P7 lowering 产出的 `p7.temporal.sequence_within_bars@1.0.0` EventSpec；窗口按 bar 数、以发生时刻度量，bar 时长由调用方显式提供；计划格式 1.3.0 的规格须绑定上游哈希。执行开关默认关闭；未测试 |
| `outcomes/` | Phase 4（ADR-0037）首批 `OutcomeProvider`：`ForwardReturnOutcome`、`TripleBarrierOutcome`——确定性、精确 `Decimal`；horizon 与屏障是 `OutcomeLabelSpec` 参数；缺数据显式 `None`；只依赖 `core`，经 `tests/contract_suites/outcome.py` 检查。另有 `VolScaledTripleBarrierOutcome`（ADR-0088 决策 5，波动率缩放屏障）。FRAMEWORK_IMPLEMENTED / NOT_VALIDATED |
| `features/` | Phase 1 F4（ADR-0030）首批 `FeatureProvider`：`BarLogReturnProvider`、`BarRealizedVolatilityProvider`、`BarVolumeSumProvider`——确定性、精确 `Decimal`、无浮点；窗口、输出精度、`available_lag` 与输入 representation 都是 `FeatureSpec` 参数；只依赖 `core`，经 `tests/contract_suites/feature.py` 检查。ADR-0085 增补：`indicators.py`（ATR、RSI、MACD 线 / 信号、布林 %B / 带宽、VWAP、ADX、bar close / high / low）、`range_volatility.py`（Parkinson、Garman-Klass、Yang-Zhang、跳跃方差）、`microstructure.py`（taker 流量失衡、Amihud 非流动性、Corwin-Schultz 价差）；参数均无默认值 |
| `features/p7_operators.py` | P7 单序列特征算子执行 Provider（ADR-0082 §2 / §4、ADR-0099、ADR-0100 §1）：`P7StandardizeProvider`、`P7DifferenceProvider`、`P7SmoothSmaProvider`、`P7RankTsProvider`、`P7QuantileTsProvider`、`P7InteractionProductProvider`；各只服务 P7 lowering 产出的对应 definition，只用 `available_time ≤ t` 的数据、缺值传播。执行开关默认关闭；未测试 |
| `features/p7_cross_sectional.py` | P7 横截面 `rank_cs` / `quantile_cs` Provider（ADR-0100 §2）：`P7RankCsProvider`、`P7QuantileCsProvider`；总体为钉定 universe 快照在同一 bar `interval_end` 的成员，缺值成员不计入、平局取平均秩；使用自有 `CrossSectionalRequest` / `CrossSectionalResult`，不实现单序列 `FeatureProvider`，因此 `compile_plan` 对含横截面节点的计划拒绝执行（`cross_sectional_execution_unsupported`）。未测试 |
| `states/` | Phase 2（ADR-0035；FRAMEWORK_IMPLEMENTED / NOT_VALIDATED）首批 `StateProvider`：`VolatilityRegimeProvider`、`LiquidityRegimeProvider`（固定尾随窗口经验分位分桶，训练型、固定 seed）、`TrendRangeProvider`（效率比，规则型）——确定性、精确 `Decimal`；参数编码在 `StateSpec.method`、无默认值；资金费率体制为 declared-unavailable；只依赖 `core`，经 `tests/contract_suites/state.py` 检查。ADR-0085 增补 `volatility_events.py`：`VolatilitySqueezeProvider`、`ReturnShockProvider`（双特征规则型） |
