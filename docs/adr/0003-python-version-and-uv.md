## 背景

系统 Python 为 3.14.4。部分科学计算、数据与数据库相关库对最新 Python 版本的支持可能滞后。复现元组（06-experiment.md §2）要求记录并固定解释器版本。

## 决策

1. 项目解释器固定为 **Python 3.13**，由 **uv** 管理。
2. 与系统 Python **完全隔离**：项目虚拟环境使用 uv 管理的 3.13 解释器；**不修改、不依赖系统 Python**。
3. 版本由项目文件固定：`.python-version` = `3.13`，`pyproject.toml` 中 `requires-python = "==3.13.*"`。
4. 依赖锁定使用 `uv.lock`；锁文件哈希进入实验复现元组的 `environment_lock`。
5. Python 升级（如 3.14）只能通过**独立的升级评估实验**：在隔离分支中用新版本重跑金标准实验，结果一致后以新 ADR 批准。

## 实施说明

- 本 ADR 只固定版本声明文件。截至 2026-09-21，uv 中**尚未安装** 3.13（已有 3.11、3.12）。
- 执行 `uv python install 3.13` 与创建虚拟环境属于软件安装，需在 **Phase 0 开启并获授权**时执行。

## 备选方案

| 方案 | 为何未选 |
|---|---|
| 系统 Python 3.14 | 生态兼容风险；与系统耦合 |
| Python 3.12 | 可行，但 3.13 在支持周期上更长且主流库已支持 |
| conda / pyenv | uv 已安装，速度与锁定能力满足需求 |

## 后果

- 正面：解释器与依赖可复现；系统升级不影响项目。
- 负面：首次使用需下载 3.13 解释器。
- 复现性：实验记录 `python_version` + `uv.lock` 哈希。
