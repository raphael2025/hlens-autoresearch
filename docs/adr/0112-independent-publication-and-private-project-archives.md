## 依据

Raphael 直接要求：HLENS-AutoResearch 作为独立项目推送 GitHub 并开源，其他项目继续在 memex 下分项目整理归档。该直接指令授权本次 Codex 发布操作，取代 ADR-0025 中要求本仓库私有的条款及本次任务的执行者不得推送限制；日常开发授权不变。

## 决定

1. 继续使用现有 `raphael2025/hlens-autoresearch` 独立仓库，公开代码与文档；发布前检查当前文件及可见 Git 历史中的凭据。
2. 开源版本采用执行前已向 Raphael 说明的默认 MIT 许可证；用户直接授权开源，但未单独指定许可证。许可证不授权第三方依赖、外部知识资料或行情数据，仍须遵守其自身条款。
3. 当前工作发布到 `phase/1`，作为默认展示分支；`main` 的稳定基线不因公开发布而自动升级。公开发布不代表 Phase 1 完成，不重开冻结阶段，不晋升策略。
4. 公开文档保留已知问题、独立审查和验收边界。此次只修改发布文档、许可证和已有示例的格式，不修改生产实现。
5. `raphael2025/memex` 保持私有。项目说明位于 `10-projects/<name>/`，独立源码快照沿用 `old/local/<name>/`。归档保留原始路径、文件摘要和排除清单。
6. 不移动或删除 WSL 原项目，不停止服务，不复制凭据、数据库、原始行情、依赖环境等运行资产；不删除其他独立远端仓库。
7. 源码快照不等于完整 Git 历史备份；旧快照/历史仍保留，新增快照单独标日期。

## 发布证据

具体检查结果和公开后的核验记录见 [发布记录](../reviews/2026-10-03-publication.md)。实际远端可见性由 GitHub 核验，不以本文状态替代外部状态。
